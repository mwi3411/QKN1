4158.1.1 : Documents Programming Task Component Parts

The learner documents the required component parts of a complex programming task. 

INTRODUCTION
In this task you will demonstrate algorithmic thinking by creating a flowchart and corresponding pseudocode for a program that will perform data analysis. Your work should show how the logic of the program is represented across both artifacts and how it can guide program implementation (Task 2).

 

Tasks in this assessment are designed to be completed in sequence. You should complete Program Planning (Task 1) before beginning Program Implementation (Task 2).

SCENARIO
You have been hired by a small investment company that manages an equity fund comprised of 156 U.S. companies across multiple industries. The fund managers are looking to rebalance the fund’s holdings and would like you to provide an analysis of the companies’ recent financial performance.



For this task, plan the logic for that program by creating both a flowchart and pseudocode. Use the data dictionary below to interpret the data fields used in the analysis. In part A, represent the required data analysis at a logical level (e.g., grouping, filtering, calculating, and sequencing), rather than at the level of specific code or syntax.



QKN1 Data Dictionary

Column Name

Description

Business ID

Unique identifier for each business. Not used as a numeric variable in analysis.

Business State

U.S. state where the business is located.

Total Long-term Debt

Total long-term debt in U.S. dollars.

Total Equity

Total equity in U.S. dollars.

Debt to Equity

Ratio of Total Long-term Debt ÷ Total Equity.

Debt to Income

Ratio of Total Long-term Debt ÷ Total Revenue.

Total Liabilities

Total liabilities in U.S. dollars.

Total Revenue

Total revenue in U.S. dollars.



Required Data Analysis

•   Identify the data set as the input for the program.
•   Identify duplicate rows and determine how they should be handled.
•   For the numeric variables, calculate descriptive statistics by state, including mean, median, minimum, and maximum, and store the results.
•   Identify businesses with negative values in the “Debt to Equity” column.
•   Calculate the debt-to-income ratio for each business in the data set and determine how to handle division by zero when revenue is zero. 
•   Combine the debt-to-income ratio results with the original data set.
 
Your flowchart and pseudocode should reflect the sequence of data analysis steps and work together to represent the logic for how the program will process the data from input to output in Task 2.

A.  Using a digital flowcharting tool of your choice (LucidChart, smartdraw, etc.), create a flowchart for a program that will perform the data analysis defined in the scenario.
 

The flowchart should:
•   represent the sequence of data analysis steps and the logic needed to complete them,
•   use standard flowchart symbols appropriately, including decision indicators when applicable,
•   include logic to handle required conditions from the data analysis, including division by zero when revenue is zero; and
•   show a complete and logical flow from start to end.

B.  Write pseudocode for a program that will perform the data analysis defined in the scenario.
 

The pseudocode should:
•   reflect the sequence of data analysis steps represented in the flowchart, and
•   outline the program’s logic in a structured and easy-to-follow format.

C.  Discuss the relationship between the flowchart and pseudocode by doing the following:
1.  Describe the logic behind the flowchart and pseudocode, including how they work together to represent the program’s logic.
2.  Explain how your pseudocode relates to your flowchart and how it supports the program’s logic.
